# EZTools module: EZHazeKill as a PCL process with Real-Time Preview — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the EZHazeKill script (1.1.0) with a native process `EZHazeKill` in a new module `EZTools-pxm`. It uses the same math, and adds PixInsight's own Real-Time Preview, process icons, ProcessContainer and history replay. The script package is dropped in the same release, and the module package removes the old script files.

**Architecture:**
- The math is a PCL-free engine, `modules/ez-tools/src/hazekill/`, which ctest checks against goldens generated by `hk_lib.py`.
- The module layer (`src/module/`) follows the Process/Instance/Interface/Parameters pattern of Planetary and GaiaDepthGrade.
- The sky estimate is measured once, on the target view's full-resolution image, and cached per view. Execute and every RTP rendition apply that cached estimate, so a preview at any zoom shows the pixels Execute writes.
- Phase 2 (Lqef quad-band magenta/green) is a separate, gated phase at the end.

**Tech Stack:** C++20, PCL 2.13.0 (module layer only), Catch2 amalgamated (from `modules/nukex/third_party/catch2`), Python 3 + numpy/scipy/xisf (goldens and parity), the Rocky 9 build container.

**Spec:** `docs/superpowers/specs/2026-11-10-ezhazekill-design.md` (the design study; sections 3 and 4 and decisions 1, 3, 5 and 6), plus the shipped reference implementation `scripts/ez-stretch/src/scripts/EZ Stretch BSC/EZHazeKill.js` 1.1.0 (commit `afcdea56`). The script is the behavioural spec: parameters, constants, console report and stretched-image note. The offline reference is `scripts/ez-stretch/test/hk_lib.py` (`hk_v11`).

## Decisions needed before Task 1 (Scott)

1. **Licence of the module code.** `EZHazeKill.js` is CC BY-NC 4.0, "Copyright (c) 2026 EZ Stretch BSC". A C++ port of it is a derivative unless the copyright holder relicenses it. The options are:
   - keep `modules/ez-tools/` under CC BY-NC 4.0, and add it to the LICENSE carve-out and the README; or
   - relicense the port as BSD-3, like the rest of the repo.

   The doc page, the package description and the file headers in Tasks 1, 3 and 5 follow this choice. CPD rule 7.3 (the PCL acknowledgement) applies either way.
2. **PixInsight floor.** Every module is built against PCL 2.13 and needs PixInsight ≥ 1.9.6. `module_platform_block` puts EZTools in the `1.9.6:2.0.0` block. When the script zip is retired, users on 1.8.0–1.9.5 keep their installed 1.1.0 script, which has the corrected math, but get no further updates. Recommended: accept this, which is why 1.1.0 ships first.

## Global Constraints

- Module id `EZTools`, process id `EZHazeKill`, parameter ids `amount`, `neutralize`, `targetLevel`. All are STABLE: never rename them. The parameter ids are the script's `Parameters` keys.
- Defaults and ranges:
  - Amount 0.5, range 0–1;
  - Neutralize 1.0, range 0–1;
  - Target 0.05, range 0–0.5.
- Fixed constants:
  - tile 64 px;
  - sky tiles = darkest 10% by tile luminance;
  - noise floor 4σ;
  - toe ε = max(1e-6, 2σ);
  - stretched note when max σ > 0.03 × mean sky.
- Math is exactly `hk_lib.hk_v11` (q=10):
  - median = mean of the two middle values for an even count;
  - percentile = numpy "linear";
  - tile selection `L <= percentile`;
  - partial edge tiles dropped;
  - an image smaller than one tile is a single tile;
  - output clamped to [0,1] after the toe.
- Arithmetic is in double, and samples are written back in the image's own sample type.
- PCL 2.13.0 from the container (`tools/build-env/Containerfile`, `PCLDIR=/opt/pcl`), C++20. There is no pin of its own and no host build is shipped (CLAUDE.md 4a). No OpenMP.
- Every PixInsight launch goes through `tools/pi-headless.sh`. Test settings slots: 99 (headless probe) and 92 (GUI smoke), wiped before and after each run. The NAS is read-only.
- Docs: `modules/ez-tools/doc/EZHazeKill/EZHazeKill.html` deploys as `doc/tools/EZHazeKill/` (CPD 6.1). It must state no network, no external programs and no files written.
- Release: `./release.sh` only. Bump `src/module/EZToolsVersion.h` and `modules/ez-tools/package-description.xml` together; descriptions name only their own version.

## Review Focus

1. **Non-finite samples (NaN/±Inf).** PixInsight images can hold them, and `hk_lib` has no defined behaviour for them. Expected: Execute refuses with "EZHazeKill: the image contains NaN or infinite samples" and leaves the image unchanged. The RTP shows the image unchanged with that text in `info`. Test: Task 1 `MeasureSky` returns `ok=false`; Task 3 probe case `nan_refused`.
2. **Integer images (8/16/32-bit).** The script's PixelMath rounds to the sample type. Expected: identical to the float result after rounding (|Δ| ≤ ½ ULP of the type). Test: Task 3 probe case `uint16_rgb`, compared with `round(hk_v11(x/65535)*65535)`.
3. **Tiny or degenerate images.** These are smaller than 64 px, or have fewer than 10 tiles (for 10%, at least one tile is always selected), or are constant or clipped black (σ = 0, so ε = 1e-6 and the floor is 0). Expected: no crash, `hk_lib` numbers, no NaN in the output. Test: Task 1 goldens `tiny_40x30_rgb`, `flat_constant`, `black_clipped`.
4. **RTP after the image changes.** The image is edited by another process, by undo/redo or by a crop, or the user switches the RTP between a main view and its preview. Expected: the next rendition re-measures that view's own full image and never shows a stale estimate. Test: Task 2 `SkyCache` invalidation; Task 4 GUI smoke step "apply Invert, RTP changes".
5. **Preview views as targets.** Expected: on a preview, both Execute and the RTP measure the preview's own pixels, not the main view's. That matches ProcessImplementation semantics, so the preview equals the result. Test: Task 3 probe case `preview_target` (sky equals `hk_v11` on the cropped region).
