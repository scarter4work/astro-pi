# Professional M42 reference renders — provenance & licensing

Per design §5.5, attribution and source travel with every reference. All five are
optical broadband color full-nebula renders of M42 (Orion Nebula), chosen to share
a palette class (RGB-like) so the Phase 0 ranking test is not confounded by
narrowband/IR palette mismatch (§2.3). Narrowband (eso0421a) and infrared
(eso1006a, eso0104a) M42 renders were deliberately excluded.
