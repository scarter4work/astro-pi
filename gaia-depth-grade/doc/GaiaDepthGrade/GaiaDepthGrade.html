Gaia Depth Grade

A depth grade for astrophotographs driven by measured Gaia star distances — script version 1.0.13, sidecar version 1.0.8 (Linux x64).

What it does

Gaia Depth Grade plate-solves your image, separates the stars from the rest of the image with StarXTerminator, finds each detected star in the Gaia catalogue to learn how far away it is, and then makes near stars a little brighter, larger and more saturated and far stars a little quieter. Optionally it also grades the starless layer (dust lanes forward, diffuse glow back), scaled to the spread of star distances. The result is recombined into a new image window named <image>_depthgraded. The depth is derived from Gaia distances and is physically motivated; it is not a per-pixel distance map of the gas.

The image processing runs in the sidecar, a separate program installed with the scripts (see External programs). The PixInsight scripts do the plate solving, the star separation, the local Gaia query and the final recombination.

What it needs

  • PixInsight on Linux x64. The sidecar program exists only for Linux x64; on other platforms the script stops with a message.
  • Two packages from the astro-pi repository (https://raw.githubusercontent.com/scarter4work/astro-pi/main/repository/), installed by PixInsight's update system (Resources > Updates > Check for Updates):
    • Gaia Depth Grade — the scripts and this documentation;
    • Gaia Depth Grade sidecar — the sidecar program, installed as <PixInsight>/bin/gaia-depth-grade-sidecar.
    The two are released together. If the sidecar is missing, cannot run, or is not the version the scripts were released with, the script stops and tells you to install or update both packages. The scripts never download, unpack or install any program themselves.
  • StarXTerminator by RC Astro, a separately licensed PixInsight module that you install and license yourself. Gaia Depth Grade uses it through PixInsight's process interface (with Generate star image and Unscreen stars enabled) to split the image into stars and starless layers. Without it the script stops with a message.
  • A plate-solvable image. Plate solving uses PixInsight's own ImageSolver script with your ImageSolver settings; the image's RA/DEC and focal-length keywords help it.
  • For the default offline mode: PixInsight's local Gaia DR3 (or DR3/SP) database files — the ones PixInsight uses for plate solving — configured in PixInsight.

Using it

Open an image and run Script > scarter4work > Gaia Depth Grade.

  1. Prepare works on a duplicate of the target (your image is never modified): plate solve, star separation, Gaia query, star detection and matching. The status line then reports how many detected stars were matched to Gaia.
  2. Preview / Update re-renders a screen-stretched preview, with a 1:1 inset you move by clicking the preview, after you change the sliders.
  3. Execute renders at full resolution and opens the result as a new window.

Offline (local Gaia DR3), checked by default, takes distances from parallaxes in your local Gaia database. Unchecked, the sidecar queries the ESA Gaia archive for Bailer-Jones geometric distances (more sources; on dense fields the archive can take several minutes).

The package also installs gaia_depth_grade.js, a non-interactive variant for automation: it grades the active image (or the file named by the GAIA_DEPTH_INPUT environment variable) with the online catalogue and, if GAIA_DEPTH_OUTPUT is set, saves the result there. Unlike the dialog it replaces the input window's image with its starless layer.

Network connections

Offline mode (the default)

Gaia Depth Grade makes no network connections. The Gaia query reads your local database through PixInsight's Gaia process, and the sidecar works on local files only.

Online mode (Offline unchecked, and gaia_depth_grade.js)

The sidecar connects to the ESA Gaia Archive, https://gea.esac.esa.int/, over HTTPS (TCP port 443) with the server certificate verified. It makes no connection to any other host. During one Prepare it:

  1. reads the archive's status notices (/tap-server/notification); any notice, such as planned maintenance, appears in the PixInsight console;
  2. submits one asynchronous ADQL query (/tap-server/tap/async) for the Gaia DR3 sources brighter than G = 18 in a circle around the image centre, joined with the Bailer-Jones distance catalogue (gaiadr3.gaia_source and external.gaiaedr3_distance); polls the job until it finishes; and downloads the result table. A failed job is submitted again, up to three attempts in all.

What is sent: the query text, which contains the image's centre coordinates and radius and the magnitude limit. No image data, no personal data, no identifiers. What is received: a table of star positions, magnitudes and distances — data, never executable code. The result is cached (see Files) so a repeated Prepare of the same field does not query again.

Plate solving

Plate solving is done by PixInsight's ImageSolver script with your own ImageSolver settings. If those settings select an online star catalogue (for example VizieR), ImageSolver contacts that service; with a local Gaia database it does not. This is ImageSolver's behaviour, configured by you, in either mode.

Gaia Depth Grade sends no telemetry and checks for no updates; updates come only through PixInsight's update system.

External programs

ProgramWhen and why
<PixInsight>/bin/gaia-depth-grade-sidecar The sidecar: the Python image-processing core of Gaia Depth Grade, frozen into one program with PyInstaller (it contains its own Python 3.14 interpreter and NumPy, SciPy, Astropy, photutils, astroquery and Pillow). It is installed and updated only by PixInsight's update system, from the signed astro-pi repository (package Gaia Depth Grade sidecar). The scripts run it once with --version to check it, then once per step: footprint, prepare, preview, render and nebula (dialog) or grade (gaia_depth_grade.js). Its working directory is the private working directory described under Files, and every path passed to it is inside that directory. Each run starts the program's own start-up code once more (PyInstaller one-file mode); it starts no other program.
/usr/bin/env Your system's standard env utility, used only to start the sidecar with PixInsight's LD_LIBRARY_PATH removed (/usr/bin/env -u LD_LIBRARY_PATH <sidecar> ...), so that the sidecar uses its own and your system's libraries rather than PixInsight's.

No other program is started. StarXTerminator, ImageSolver, PixelMath and PixInsight's Gaia process run inside PixInsight as ordinary processes and scripts.

Files written outside the PixInsight installation

Everything Gaia Depth Grade writes lives in one private working directory of your own:

$XDG_CACHE_HOME/gaia-depth-grade/ — by default ~/.cache/gaia-depth-grade/

The scripts create it, and its subdirectories, with mode 0700 (only you can list, read or write them), and check them before every use without following links: each must be a real directory — not a symbolic link — owned by you. If that is not the case the script stops and says why; it never writes through a link or into a directory someone else owns. It never uses a shared, predictable location such as /tmp/gaia_depth_grade.

One location is outside the working directory:

LocationContentsLifetime
/tmp/_MEIxxxxxx/ (in $TMPDIR if set) The sidecar unpacks its bundled Python runtime (about 175 MB) into a new directory each time it starts. The directory has a random name and mode 0700, created afresh for every run. Removed by the sidecar when it exits. Only a crash or a forced kill can leave one behind; it is then safe to delete.

Nothing else is written outside the PixInsight installation, and nothing is written into the installation except by PixInsight's update system when it installs the packages. The result image is an ordinary PixInsight window; it is saved only if you save it.

Files it reads

  • The image you select.
  • Offline mode: PixInsight's settings files ~/.PixInsight/core-*-pxi.settings, read only, to find the Gaia DR3 database files configured for plate solving, and those database files (through PixInsight's Gaia process).

Leftovers from earlier versions

Versions 1.0.12 and earlier downloaded the sidecar themselves. The current version never uses or touches these locations; you can delete them:

  • ~/.astro-pi/gaia-depth-grade/ — the previously downloaded sidecar program (about 100 MB).
  • <PixInsight>/bin/.cache/ — online Gaia query results that earlier versions could write into PixInsight's program directory (only if that directory was writable).
  • /tmp/gaia_depth_grade/ — the working files of earlier versions, if it is yours.

Third-party software

The sidecar program bundles third-party software (CPython, NumPy, SciPy and their OpenBLAS/GFortran runtime, Astropy, pyerfa, photutils, astroquery, Pillow and others). Their licences are installed with it, in gaia-depth-grade-sidecar-THIRD_PARTY_NOTICES.txt in this folder.
