Planetary-pxm.so contains code from the component listed below, statically
linked or compiled in from header files. The list comes from the linker map
of the module build, so it names what is actually inside the module, not
merely what is on the link line. The component's copyright notice, licence
conditions and disclaimer follow, as its licence requires for binary
redistribution.

  1. PixInsight Class Library (PCL) 2.9.4 .... PixInsight Class Library
                                                License 2.0

Not inside the module: PCL's link line also names its bundled LZ4, Zstandard,
zlib, RFC 6234 (SHA), Little CMS and C/C++ Minpack libraries, but the linker
takes no object from any of them into Planetary-pxm.so. The GCC runtime pieces
linked in (libstdc++_nonshared, libgcc) are covered by the GCC Runtime Library
Exception and require no notice. The SER and AVI readers, the debayer and
the PlanetaryStack engine (including its FFT) are this module's own code.
