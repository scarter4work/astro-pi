What's new, what's refactored, what gets deleted. Each item lists its single responsibility — if you can't articulate that in one sentence, the boundary is wrong.

New code (single-responsibility scoped)
src/lib/core/
  Filter.{hpp,cpp}                  → typed wrapper: (FilterClass, FilterName, Camera, BandwidthSpec)
                                       lives in core because everyone downstream consumes it

src/lib/io/
  FilterClassifier.{hpp,cpp}        → FITSMetadata → Filter; emits "needs disambiguation"
                                       result if FILTER + INSTRUME insufficient
                                       (extends, doesn't replace, the existing
                                        filter_classifier.cpp in src/module/)

src/lib/calibration/   ← new directory
  QEDatabase.{hpp,cpp}              → loads share/qe_database.json + ~/.nukex4/qe_overrides.json,
                                       exposes lookup(Camera, wavelength) and
                                       lookup(FilterName) → BandwidthSpec
  ChannelDecomposer.{hpp,cpp}       → builds Q-matrix per (Filter, Camera), returns
                                       a per-pixel solver: (R,G,B) → recovered line channels

src/lib/compose/       ← new directory
  Palette.{hpp,cpp}                 → calibrated emission-line color vectors at 656/501/672 nm
                                       in CIE-Lab; "no greens by construction" enforced here
  ColorComposer.{hpp,cpp}           → cube → final RGB; Lab/LCH composite default,
                                       continuum-subtract opt-in mode

src/module/
  DisambiguationDialog.{hpp,cpp}    → PI dialog: "FITS FILTER missing/unknown for N frames —
                                       which class is this?" Only shown when classifier asks.

share/
  qe_database.json                  → 22 sensors + 55 cameras + 87 filters
                                       (research agent's output, normalized + reviewed)

tools/
  import_qe_research.py             → one-shot transform from research JSON to shipping format
                                       (drops _meta, validates schema, writes share/)
Refactored existing code
src/lib/core/channel_config.{hpp,cpp}
  → driven by Filter+FilterClass instead of StackingMode enum
  → slot allocation is filter-class-shaped (Ha+OIII vs R+G+B vs L+R+G+B)
  → mixed-class cube takes the union of all filter classes seen in the batch
  → REMOVES the dead output_rgb_mapping[3] field

src/lib/core/cube.{hpp,cpp} + SubcubeVoxel
  → variable-arity slot layout (replaces hardcoded MAX_CHANNELS arrays)
  → each slot still holds Welford + histogram per pixel
  → memory layout stays SoA-friendly for GPU — slots are contiguous arrays

src/lib/stacker/stacking_engine.cpp
  → REMOVES the hardcoded OSC_RGB at line 107
  → per-frame accumulate calls ChannelDecomposer.solve(frame R,G,B) → routes into voxel slots
  → multi-filter batches: dispatch on per-frame filter class

src/module/NukeXInstance.cpp
  → wires QEDatabase + FilterClassifier + ChannelDecomposer at execution start
  → emits ImageWindow from ColorComposer output (always 3-channel RGB)
  → optional 2nd window for "raw line emission" channels (Ha mono, OIII mono)
    if user wants to do their own combine

src/module/NukeXInterface.cpp
  → new "QE override file…" file picker (optional; defaults to ~/.nukex4/qe_overrides.json)
  → no other UI changes (honors simple-UI rule)
