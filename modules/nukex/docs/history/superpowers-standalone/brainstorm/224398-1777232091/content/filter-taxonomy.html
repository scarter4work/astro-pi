Reframe — don't taxonomize, infer continuously

Don't enumerate filter classes. Instead, for each filter, store (center wavelength array, FWHM array). Compute decomposition matrix from those numerics. Treat LPro as "1 line at 550nm × 300nm FWHM", treat Ha as "1 line at 656nm × 6nm FWHM". One pipeline, no enum.

Output combining hint (so you can sanity-check): Pure-NB → calibrated palette (option A from earlier — no greens). Pure-broadband → natural color. Mixed (LRGBSHO) → natural-color base + emission-line enhancement via Lab/LCH (broadband provides L+chrominance, NB enhances where it's strong) — that's the "wider bandpass" output you mentioned.
