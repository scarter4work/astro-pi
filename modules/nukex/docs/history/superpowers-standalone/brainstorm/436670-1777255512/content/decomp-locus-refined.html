Refining Decomposition Locus — When Does Q-Solve Run?

Both keep DebayerEngine naive. Both let Phase A be streaming I/O. They differ in what voxel slots hold and where the linear Q-solve runs.

Variant 1 — Q-solve at accumulate (what Section 3 showed)
Phase A (per-frame streaming I/O):
  read frame f → debayer naive → align → cache
  for each pixel: Q_solve(R,G,B) → (Ha, OIII) → voxel.slots["Ha"].update(Ha)
                                                voxel.slots["OIII"].update(OIII)

Voxel slots (LRGBSHO case):    {Ha, OIII, SII, L, R, G, B}    ← 7 semantic slots
Phase B fits + selects on:     each semantic slot
ColorComposer reads:           semantic slots directly

Trade-off: voxel slots hold derived values; Q-solve happens at streaming time
           per-frame; if user updates QE override JSON later, must re-stack.
Variant 2 — Q-solve at Phase B (more subcube-y)
Phase A (per-frame streaming I/O — pure routing, no math):
  read frame f → debayer naive → align → cache
  for each pixel:
    if filter==HaO3: voxel.slots["R_HaO3"].update(R), G_HaO3.update(G), B_HaO3.update(B)
    if filter==S2O3: voxel.slots["R_S2O3"].update(R), G_S2O3.update(G), B_S2O3.update(B)
    if filter==L:    voxel.slots["L"].update(value)
    if filter==R:    voxel.slots["R"].update(value)
    ...

Voxel slots (LRGBSHO case):    {R_HaO3, G_HaO3, B_HaO3,             ← 6 raw filter-grouped
                                 R_S2O3, G_S2O3, B_S2O3,
                                 L, R, G, B}                          ← 4 broadband     = 10 total

Phase B (per-pixel cube-time work — THIS is where semantics emerge):
  for each pixel:
    fit + select per raw slot → best (R_HaO3, G_HaO3, B_HaO3) etc.
    Q_solve(camera, "HaO3") on (R_HaO3, G_HaO3, B_HaO3) → (Ha, OIII_HaO3)
    Q_solve(camera, "S2O3") on (R_S2O3, G_S2O3, B_S2O3) → (SII, OIII_S2O3)
    OIII = sample-weighted_mean(OIII_HaO3, OIII_S2O3)   ← multi-source OIII merge
    derived slots = {Ha, OIII, SII, L, R, G, B}

ColorComposer reads:           derived slots

Trade-off: ~50% more voxel slot memory in Phase A; Phase B does the algebra;
           "voxel is record" holds raw data; user updates QE override → re-run
           Phase B only, no re-stacking; continuum subtraction has natural-RGB
           voxels right there to use.
