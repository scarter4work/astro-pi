Phase 8 — Data Flow

Two paths: Execute (left) and Rate (right). Shared state: rating DB + coefficients file.

Execute flow
  1. User clicks Execute
  2. Phases A / B / C → result.stacked (linear)
  3. Read FITS metadata (FILTER, OBJECT, BAYERPAT)
  4. classify_filter(meta) → FilterClass
  5. Auto-selector → stretch name (e.g. VeraLux)
  6. NEW compute_image_stats(stacked) → 25-dim stat vector
  7. NEW Load active ParamModel for this stretch (Layer 3 if on disk, else Layer 2)
  8. NEW model.predict(stats, target_hint) → params
  9. NEW Mutate StretchOp with predicted params + log which layer answered
  10. Stretch pipeline runs → stretched window opens
  11. NEW Create PENDING DB row (run_id, stats, params, stretch, target_hint, ts)
  12. NEW Show rating popup (unless opted out);
    Interface's "Rate last run" button lights up
Rate flow
  1. User moves sliders, clicks Save
  2. DB row for run_id updated with ratings + rated_at
  3. Retrain this stretch's model (foreground, ~50 ms):
    • Load all rated rows for this stretch (bootstrap + user)
    • Fit ridge regression per param via Eigen
    • Write coefficients to ~/.nukex4/phase8_user_model.bin
  4. Invalidate cached ParamModel for this stretch
  5. Next Execute picks up refreshed Layer 3
Skip / opt-out
Skip — PENDING row stays; Rate button still available.
Don't show again — popup disabled in persistent settings; button still works.
Never rated rows stay PENDING; can be pruned after 30 days via housekeeping.
