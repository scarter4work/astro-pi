Phase 8 — Architecture

The 4-layer prediction stack, how data flows, what writes each layer.

Prediction flow — "Auto" or any stretch dropdown
Layer 1 — Factory defaults
Immutable constants in each StretchOp.
Written never. "Reset to factory" reverts here.
↓ if model absent / confidence low
Layer 2 — Community bootstrap
Ridge model fit from Scott's labeled corpus.
Written at release time, shipped as coefficients file.
↓ always additive
Layer 3 — User-learned current
Same ridge model retrained on
bootstrap rows + user's local ratings.
Written whenever user saves a rating.
↓ per-run
Layer 4 — Per-image prediction
Apply the current model to
this image's stats → final params.
Reset / escape hatches
  • Reset to factory — ignore all model layers, use Layer 1 constants.
  • Reset to bootstrap — discard user ratings, use only shipped Layer-2 model.
  • Explain — print Layer-3 coefficients + top-3 most similar past runs (kNN on DB) for transparency.

Key invariants

  • Layers 2, 3, 4 are the same ridge model at different training snapshots + a final predict() call. Not three separate models stacked.
  • Layer 1 is the only hard-coded constant in the system. Every coefficient in layers 2/3 comes from labeled data.
  • Cold start (user has zero ratings): Layer 3 = Layer 2 (shipped model, unmodified).
  • Retraining is closed-form ridge regression — runs in <50ms on a laptop even for thousands of rows. Happens on rating save.
